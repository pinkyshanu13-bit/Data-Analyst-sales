# Sales Analytics Website

A responsive browser dashboard for the Sales Data Analysis project, built with HTML, CSS, Flask, Pandas and Chart.js.

## Run on Windows
1. Extract this ZIP file.
2. Open the extracted folder in VS Code.
3. Open Terminal > New Terminal.
4. Run `python -m pip install -r requirements.txt`
5. Run `python app.py`
6. Keep the terminal running and open Google Chrome.
7. Visit `http://127.0.0.1:5000`

Press Ctrl+C in the terminal to stop the local website. The sample CSV contains fictional learning/demo data. Chart.js is loaded from a CDN, so internet is needed for charts.
